## Selected work

### 🔎 [Comparing OCR engines on a mortgage form](https://github.com/jshaam7/ocr-engine-comparison)
Compared Tesseract, EasyOCR, and PaddleOCR for text extraction and layout preservation. In this project’s comparison, PaddleOCR produced the most complete output; pre-resizing resolved a documented recognition issue.

`Python` `Tesseract` `PaddleOCR` `EasyOCR` `OpenCV` · [Open the Colab notebook](https://colab.research.google.com/github/jshaam7/ocr-engine-comparison/blob/main/Compare_3_OCR_Engines_on_a_Mortgage_PDF.ipynb)

### 📊 [Consumption, household profiles & well-being](https://github.com/jshaam7/consumption-wellbeing)
Explored associations between household consumption and life satisfaction across **65,544 filtered household records**, using survey-weighted analysis, household profiles, and spline models. Development uses one of 20 data implicates; results are observational, not causal.

`R` `Survey analysis` `Statistical modelling`

### 🚲 [Cyclistic bike-share analysis](https://github.com/jshaam7/cyclistic-bike-share-analysis)
Analyzed **800,000+ trips** to compare casual and member riding patterns, then translated weekday/weekend and time-of-day differences into membership-conversion recommendations.

`R` `Tableau` `Data storytelling`

### 🧠 [Deepfake detection CNN](https://github.com/jshaam7/deepfake-detection-cnn-model)
Built a real/fake image-classification baseline with image preprocessing and a CNN. The repository reports **~82% test accuracy** for its provided run—a project evaluation result, not a production claim. Completed as an equal collaboration with Dishika.

`TensorFlow` `Keras` `OpenCV`
